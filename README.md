# My Habit Tracker

A personal, mobile-friendly habit tracker designed for GitHub Pages.

## Features
- Daily habit completion
- Previous/next day navigation
- Streak tracking
- Monthly completion percentage
- Monthly bar chart
- Add, edit, and delete habits
- PWA install support
- Offline caching
- No backend or account required

## GitHub Pages
1. Create a new GitHub repository.
2. Upload all files in this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and open the generated GitHub Pages URL.

## Data
Logs are stored in the browser's localStorage. They do not automatically sync between devices. Clearing browser/site data can remove the logs.
